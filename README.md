# Fiyin — Social Media Manager Portfolio

This is a custom, responsive portfolio website built from scratch with HTML, CSS and a tiny bit of JavaScript.

## Files

- `index.html` — website structure and content
- `style.css` — design, layout and responsive styling
- `script.js` — mobile navigation
- `images/fiyin.jpg` — supplied profile photo

## Publish for free with GitHub Pages

1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository named `YOURUSERNAME.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
4. Go to **Settings → Pages**.
5. Under the publishing source, choose your main branch and root folder.
6. GitHub will publish the site at `https://YOURUSERNAME.github.io/`.

GitHub's official guide:
https://docs.github.com/en/pages/quickstart

## Before publishing

Replace any portfolio wording that you want to change, and add real screenshots/thumbnails from your YouTube and Instagram if you want the work section to show your actual posts instead of the designed placeholders.

Your contact email is already connected. WhatsApp is linked to the phone number supplied for this portfolio.
