# FIYIN — Editorial Portfolio

## Add your pictures — exact steps

Open the `assets` folder.

Put your TWO pictures inside it and name them exactly:

`portrait-1.jpg` — the main homepage picture  
`portrait-2.jpg` — the About-section picture

The website already points to those exact locations:

`assets/portrait-1.jpg`  
`assets/portrait-2.jpg`

### If your pictures are PNG

PNG is completely fine. Just rename the files:

`portrait-1.png`  
`portrait-2.png`

Then open `index.html` and change only `.jpg` to `.png` in the two image lines.

### GitHub Pages structure

Your repository must look EXACTLY like:

repo/
- index.html
- style.css
- script.js
- assets/
  - portrait-1.jpg
  - portrait-2.jpg

Do not upload the ZIP itself as the website. Upload/extract the actual files.

Do not use `/assets/...`; keep `assets/...` because this works correctly for a GitHub Pages project site.

If a picture is missing, the website shows a clean `YOUR PHOTO GOES HERE` placeholder instead of a broken-image icon, so you can immediately see what needs fixing.
